Phân biệt var, let và const

Tác giả: Trương Gia Hưng | Ngày đăng: 12/05/2026

Mục lục:
  • 1. Phạm vi hoạt động
  • 2. Code thực tế
  • 3. Trích dẫn

1. Phạm vi hoạt động (Scope)

Khai báo biến là bước cơ bản nhất. JavaScript trước đây chỉ có var, nhưng ES6 đã mang đến sự đột phá bằng let và const.

Sự khác biệt lớn nhất là phạm vi: var dùng phạm vi hàm, còn let/const dùng phạm vi khối (block scope). Cải tiến này giúp tránh lỗi ghi đè dữ liệu.

Hãy thử nhấn F12 mở Console, gõ code và xem output trả về: undefined hoặc giá trị thực tế.

3. Trích dẫn

"Bất kỳ kẻ ngốc nào cũng có thể viết code để máy tính hiểu. Lập trình viên giỏi viết code để con người hiểu."
- Martin Fowler

2. Code thực tế

Dưới đây là 2 đoạn code minh họa ngắn gọn sự khác nhau giữa biến có thể thay đổi và hằng số. 


// 1. Dùng let (Biến có thể gán lại, phạm vi khối)
let score = 10;
if (true) {
    let score = 20; // Biến này chỉ sống trong ngoặc nhọn
}
console.log(score); // Output: 10
        

// 2. Dùng const (Hằng số, không thể gán lại)
const PI = 3.14;
// PI = 3.15; // Sẽ gây lỗi TypeError
